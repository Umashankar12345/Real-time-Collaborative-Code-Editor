# Real-time Collaborative Code Editor

A powerful, web-based collaborative code editor designed to allow multiple developers to write, review, and debug code simultaneously in real time.

## 🚀 Key Features

- **Real-Time Collaboration**: Instantaneous code syncing using Socket.io for a seamless multiplayer coding experience.
- **Advanced Code Editor**: Powered by Monaco Editor (the same engine behind VS Code) with syntax highlighting, auto-completion, and multi-cursor support.
- **Custom Theming**: Switch between multiple gorgeous editor themes including VS Dark, Light, High Contrast, Dracula, and Monokai to suit your personal aesthetic.
- **Authentication**: Secure JWT-based authentication with traditional email/password and integrated GitHub OAuth and Google OAuth login options.
- **Live Preview & 3D WebGL**: Built-in 3D scene preview capabilities and interactive web environments directly in the browser workspace.
- **Modern UI/UX**: A highly polished, dark-mode first dashboard with fluid animations, interactive node-graphs, and a premium developer experience.
- **End-to-End Testing**: Comprehensive automated testing suite written in Playwright to ensure high reliability for auth flows and room synchronization.

## 🛠 Tech Stack

- **Frontend**: React, Vite, Tailwind CSS, Lucide Icons, Three.js / React Three Fiber
- **Backend**: Node.js, Express, Socket.io, MongoDB, Mongoose
- **Testing**: Playwright
